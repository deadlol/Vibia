# Vibia Studio 🚀

Welcome to the official repository for **Vibia**, an enterprise digital transformation and AI agency. 

We built this portfolio to showcase our services, our work, and our philosophy. It's designed to be fast, highly animated, and fully bilingual (English and Persian/Farsi), providing a seamless experience regardless of which language you prefer.

## ✨ What's inside?

- **Bilingual Core:** Native LTR (English) and RTL (Persian) support, switching seamlessly without page reloads.
- **Fluid Animations:** Smooth, cinematic transitions between panels and edge navigation using modern motion libraries.
- **Fully SEO Optimized:** Complete with JSON-LD schema, Open Graph tags, canonical links, robots.txt, and dynamic meta updates.
- **Responsive Design:** Looks and feels native on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

This project is built with a modern frontend stack to ensure high performance and maintainability:
- **React** – Component-driven UI.
- **Vite** – Lightning-fast frontend tooling.
- **Tailwind CSS** – Utility-first styling for quick, consistent design.
- **Motion** – For those buttery smooth layout transitions.
- **TypeScript** – Because type safety is a lifesaver.

## 🚀 Getting Started

Want to run this locally or contribute? It's super easy.

1. **Clone the repo:**
   ```bash
   git clone https://github.com/yourusername/Vibia.git
   cd Vibia
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open up `http://localhost:3000` in your browser and you're good to go!
